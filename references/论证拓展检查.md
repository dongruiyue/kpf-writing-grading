# 论证拓展检查（PRE + 五环链条）

> 用途：判断学生的正文段**展开是否充分**，并在批改时给「论证不充分」定位到具体断在哪一环。
> 适用级别：PRE 适用于 KET / PET 邮件与故事；五环链条适用于 PET article 与 FCE essay。

---

## 按级别选工具

| 级别与题型 | 用哪套 | 检查什么 |
|---|---|---|
| KET 邮件 / 故事、PET 邮件 | **PRE** | 每个要点有没有 观点 → 理由 → 例子 |
| PET article、FCE essay（议论文） | **五环链条** | 每个正文段的论证链有没有走完 |

---

## 工具一：PRE（观点—理由—例子）

学生常见毛病：给了观点就停，或给了理由没例子。

| 环节 | 要求 | 典型缺失 |
|---|---|---|
| **P** Point | 一句明确的观点 | 观点太大太泛（"Sports are good"） |
| **R** Reason | 为什么这样想 | 只有观点，没有 because |
| **E** Example | 一个具体的人/事/时间 | 只有道理，没有例子 |

**诊断用法**：光有 P 是 1 环，P+R 是 2 环，P+R+E 才算展开充分。
批改时的写法不要说「内容单薄」，要说「第二点只写了观点和理由，缺一个例子」。

---

## 工具二：五环链条（论证链）

议论文的「论证」本质是一串 if-then 链条。学生最常见的毛病是**有观点、没论证**——抛出 claim 就结束，等于链条只走到 Activities 就断了。

| 逻辑模型 | 作文对应 | 学生常见问题 |
|---|---|---|
| Resources / Inputs | 核心观点（topic sentence） | 观点模糊或太大 |
| Activities | 机制解释：这件事具体怎么运作 | 跳过，直接喊结论 |
| Output | 直接结果 | 写到这就停了（链条只走一半） |
| Outcome | 对当事人／群体的影响 | 缺失，论证悬在空中 |
| Impact | 回扣题目 + 更大的意义 | 与中心论点脱节 |

### 完整示范（题目：政府应否投资公共交通）

> **观点（Inputs）**：投资公共交通能缓解城市拥堵。
> **机制（Activities）**：地铁和公交网络覆盖更密、班次更可靠后，通勤者才愿意放弃私家车。
> **直接结果（Output）**：高峰期路面车辆减少。
> **群体影响（Outcome）**：通勤时间缩短、尾气排放下降。
> **回扣＋升华（Impact）**：城市不仅更通畅，也更宜居，这正是交通投资的最终目的。

### 诊断定位器（批改时用这一栏）

| 链条断在哪 | 该写什么诊断 | 学生要补什么 |
|---|---|---|
| 断在 **Activities** | 观点没展开 | 补 how / why（这件事怎么做到的） |
| 断在 **Output** | 有解释但没推出结果 | 补 so / therefore 那一步 |
| 断在 **Outcome** | 论证没落到「谁受益、怎么受益」 | 补对人或群体的具体影响 |
| 断在 **Impact** | 结尾不回扣 thesis，或升华跑偏 | 回扣中心论点，不要另起话题 |

### 自查句（交给学生）

> 「我每个 If 后面的 Then，写出来了吗？」缺哪环补哪环。

---

## 连接词按链环功能分区（教连接词的抓手）

不要让学生背连接词列表，而是按「我要跨过哪个箭头」来选词：

| 跨过哪个箭头 | 用这些词 |
|---|---|
| Inputs → Activities（资源到活动） | because / as / since |
| Activities → Output（活动到产出） | so that / consequently / as a result |
| Output → Outcome（产出到成效） | this means / which leads to |
| Outcome → Impact（成效到影响） | ultimately / in the long run |

---

## 批改时的接入点

1. **第 2 步评分**：Content 分除了核对要点覆盖，还要看每个要点的链条走到哪一环；断点写进给分依据
2. **第 3 步逐句批改**：正文段按链条逐环标注（写到哪一环、缺哪一环）
3. **第 4 步范文**：reachable 范文要把学生断掉的那一环补上，示范完整链条
4. **第 5 步反馈**：【需要修改的地方】用链条语言写，例如「第二段只写了观点，没写它怎么起作用」，比「论证不充分」具体

## 一句话总结

**每一步都要证明下一步会发生。** 这既是项目评估的逻辑，也是议论文说服力的来源。
