# kpf-writing-grading · 剑五作文批改工作流

一个面向 AI 编程助手（Kimi Code / Claude Code / Codex 等）的 **user-level skill**：英语老师发来剑桥五级（KET / PET / FCE）作文题照片 + 学生手写作文照片，助手按官方评分标准完成**批改、评分、逐句修改、reachable 范文、学生版纯文本反馈**，可选生成**单文件 HTML 批改报告**（带一键转图片按钮，直接发家长微信）。

## 为什么值得用

- **评分挂在官方量表上**：三套 rubric（KET / PET / FCE）含 band descriptor、定性档位、字数硬线，不是凭感觉打分
- **先确认再评分**：手写转写必须经老师确认后才进入评分，杜绝认错字导致的误判
- **字数是硬线**：写不满词数线直接判不过（自定规则，可改）
- **交付两个独立产物**：学生版纯文字反馈（整块复制发微信）+ HTML 批改报告（家长/学生视角，无教师工作语言）
- **机器卡口**：内置校验脚本，交付前自动检查反馈格式、报告结构、禁语、样板残留

## 安装

把本目录复制到你的 skills 目录之一：

```bash
# Kimi Code / 跨运行时
cp -r kpf-writing-grading ~/.agents/skills/

# 或 Claude Code
cp -r kpf-writing-grading ~/.claude/skills/
```

## 使用

对 AI 助手说：

> 批改这篇作文
> （附上：作文题照片 + 学生手写作文照片，或两者的文字版）

助手会走六步流程：

1. 确认上下文（缺题目会问，不猜）
2. 转写 + 字数统计，等你确认
3. 按官方量表评分（先执行字数硬线）
4. 逐句批改（错误分类 + 学生听得懂的原因）
5. reachable 范文（跳一跳够得着，不是炫技版）
6. 学生版纯文本反馈（固定格式，可直接发微信）

然后主动问你是否生成 HTML 报告。说「生成报告」即可。

## 目录结构

```
kpf-writing-grading/
├── SKILL.md                      # 主流程（六步 + 红线 + 校验清单）
├── rubrics/
│   ├── ket.md                    # KET 评分标准（三项 0–5、字数硬线 25/35 词）
│   ├── pet.md                    # PET 评分标准（四项 0–5、字数硬线 90 词）
│   └── fce.md                    # FCE 评分标准（四项 0–5、字数硬线 140 词）
├── assets/
│   └── report-template.html      # HTML 报告模板（内含完整虚构示例）
└── scripts/
    └── validate-deliverables.py  # 交付前校验器
```

## 交付校验

```bash
python3 scripts/validate-deliverables.py <学生版反馈.txt> <报告.html>
```

检查：反馈五分区齐全且有序、无破折号、无 AI 句式、星级递减、分数行带小分；报告六区块齐全、截图按钮在位、无学生版反馈段回流、无占位符、无模板残留。

## 自定规则（非剑桥官方，可按教学需要修改）

| 规则 | 默认值 |
|---|---|
| PET 字数硬线 | 90 词，不足直接判不过 |
| KET 字数硬线 | 邮件 25 / 故事 35 词，不足直接判不过 |
| FCE 字数硬线 | 140 词，不足直接判不过 |
| 定性档位 | 17–20 Grade A / 14–16 Grade B / 11–13 Grade C 稳过 / 8–10 边缘 / 0–7 未到级 |
| 单篇换算 | 官方换算以两篇合计为基础，单篇只标定性档位，不标量表分 |
