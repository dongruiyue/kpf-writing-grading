# 04 · AI 批改与人工批改对比

> 这份文档回答：**AI 批改和人工批改各自擅长什么，边界在哪，为什么要「AI 干粗活 + 老师复核」。**

---

## 先说结论

这个 skill 的定位**不是替代老师**，而是：

> **AI 干粗活（转写、打分、逐句批改、格式输出），老师做只有老师能做的事（复核、教学判断、跟家长沟通）。**

如果你期待的是「完全不需要老师看的自动批改」，这个 skill 不是那个东西，也不建议是那个东西——作文批改的最终责任人应该是老师，不是机器。

## 逐项对比

### 速度

| | 人工 | AI + 复核 |
|---|---|---|
| 转写一篇手写作文 | 5–10 分钟（逐字辨认） | 30 秒（AI 识别 + 你扫一眼确认） |
| 打分 | 5–10 分钟（凭经验，但不写依据） | 1 分钟（AI 挂量表打分 + 逐项给依据） |
| 逐句批改 | 10–15 分钟 | 1–2 分钟 |
| 写学生版反馈 | 5–10 分钟 | 30 秒（AI 按定稿格式生成） |
| 生成发家长的成品 | 15–30 分钟（手写/排版） | 1 分钟（HTML 一键转图） |
| **单篇合计** | **40–60 分钟** | **5–10 分钟** |

**30 篇作文**：人工 20–30 小时 → AI + 复核 2.5–5 小时。

### 一致性

| | 人工 | AI + 校验器 |
|---|---|---|
| 同一篇作文打两次分 | 可能差 1–2 分（状态、疲劳、心情） | 校验器强制：小分和=总分、档位与分数匹配、格式统一 |
| 不同作文之间的标准 | 凭感觉浮动 | 锚定同一套 band descriptor 和官方样文 |
| 反馈格式 | 看心情写 | 定稿格式，五个分区一字不改 |

### 准确性

这是最需要诚实说的部分。**AI 不是天然比人准，也不是天然比人差。它的准确性取决于规则的质量。**

| 场景 | 谁更准 |
|---|---|
| 手写识别 | AI 快但会认错字；人慢但准。**所以流程里强制「先转写确认再评分」** |
| 挂量表打分 | AI 如果给了 rubric 和锚点，能比「凭感觉」的老师更稳定；但不如有经验的考官 |
| 识别「不算错但可更地道」的表达 | AI 容易误判为错误（characters 案例）；人更灵活。**所以 rubric 里加了「可选优化」这个类别** |
| 发现学生写作习惯的进步/退步 | AI 需要历史档案才能做；人对熟悉的学生天然有感觉 |
| 判断「这个错误是个案还是全班共性」 | **只有人能做**。AI 看到的是一篇作文，老师看到的是一个班 |

### 成本

| | 人工 | AI + 复核 |
|---|---|---|
| 金钱 | 老师的时间（最贵） | 零（开源免费） |
| 精力 | 高（重复劳动耗神） | 低（AI 干粗活） |
| 学习成本 | 无 | 需要装 AI 助手 + 复制 skill（5 分钟） |

## AI 做不好的事（必须老师来）

### 1. 判断「这是个案还是共性」

AI 改一篇作文，看到的是这一篇。两个学生都在 `characters` 上犯错，AI 会分别改两处，但只有老师能判断「这是全班都要讲的词，下节课统一处理」。

### 2. 根据学生情况调整教学策略

AI 给的是「这篇作文怎么改」，不是「这个孩子接下来怎么教」。一个「写不长」的孩子和一个「没话说」的孩子，表面上都是词数不够，但补法完全不同——前者练扩写，后者练头脑风暴。这个判断只有老师能做。

### 3. 跟家长解释分数的含义

「Grade C 边缘」是什么意思？「判为不过」是不是孩子很差？「10/20 应理解为 8–12 的区间」怎么跟家长说？这些话 AI 可以起草（skill 里有「给家长的分数解释」话术），但最终用什么语气、说到什么程度，是老师的事。

### 4. 在评分松紧之间做情境判断

同一篇作文，严格按量表给 2 分还是宽松给 3 分？AI 会按规则给一个确定的数，但有时候老师需要「这次松一点，因为孩子刚起步，不能打击信心」或者「这次严一点，因为马上考试了，要让他知道真实水平」。这种情境判断是教学智慧，不是规则能覆盖的。

### 5. 对 AI 的输出说不

校验器再强，也只能抓「格式错、算术错、规则矛盾」。「这个分给高了」「这个词认错了一个更微妙的含义」「这个反馈的语气对这个孩子太硬了」——这些只有老师能判断。**所以每一篇都必须老师复核后才发出去，这是设计意图，不是缺陷。**

## 最佳实践：分工

```
AI 做：                          老师做：
├── 转写手写作文                  ├── 扫一眼转写，纠正认错字
├── 统计字数                      ├── 确认字数
├── 按量表打分 + 写依据           ├── 复核分数，松紧自己把握
├── 逐句批改                      ├── 判断哪些错误要重点讲
├── 写 reachable 范文             ├── 决定范文是否适合这个学生
├── 生成学生版反馈                ├── 调整语气，发出去
├── 生成 HTML 报告                ├── 决定要不要发给家长
└── 记录校准日志                  └── 贴回改法，让 skill 变准
```

**一句话：AI 把「改作文」变成「看作文」，你只看 20%，但那 20% 只有你能看。**
