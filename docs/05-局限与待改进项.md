# 05 · 局限与待改进项

> 这份文档回答：**这个 skill 现在哪里不行，哪些地方还没验证，接下来要改什么。**
> 写这份文档的目的不是自我表扬，是让你在用之前就知道边界在哪。

---

## 已知局限（用之前必须知道）

### 1. 官方量表未逐页人工核对

三套 rubric 的 band descriptor 经过了 GPT6-astra 对照剑桥官方教师指南的核验（2026-09-29），但**我本人没有逐页翻阅原始 PDF 原文核对**。建议你拿到官方 handbook 后，抽 10 分钟对照一遍 rubrics 里改过的描述，这是目前唯一没做的人工验证。

### 2. FCE 全流程未实测

PET 和 KET 都跑过完整的「照片→反馈」流程并经过真实使用校准，**FCE 还没有**。FCE 的 rubric 是按 PET 的逻辑上浮写的，维度相同但标准高一档，第一次用 FCE 时如果发现行为不对，请贴回改法，我补规则。

### 3. 手写识别不完美

AI 对手写的识别准确率取决于照片质量（光线、角度、清晰度）和书写习惯。流程里的「先确认再评分」能兜住大部分，但**极度潦草的书写可能连转写都做不了**——这种情况只能你手动输入文字。

### 4. 没有官方精确换算表

单篇作文的分数到剑桥量表分（如 140–170）没有官方精确换算表，skill 用的是**定性档位**（Grade A / B / C / 边缘 / 未达）。这意味着：
- 你能告诉家长「大约是 Grade B 水平」
- 你不能告诉家长「相当于剑桥量表 153 分」
- 如果你拿到了官方的分数兑换总表，发给我，可以把精确换算补回去

### 5. ±2 容差是教研经验，不是官方数据

「分数允许 ±2 误差」这个说法来自教研实践，**剑桥官方文件里没有这个明文规定**。报告中我们用的是「参考区间」的表述，但如果你对外引用这个数字，建议说「经验上」而不是「官方允许」。

### 6. 字数硬线是自定规则

PET 90 词 / KET 25·35 词 / FCE 140 词的硬线**不是剑桥官方要求**，是这个 skill 的自定规则（为了解决「学生不知道写满字数是底线」的问题）。报告中已注明「本次练习的自定要求」，但如果你把分数截图发给其他老师或机构，他们可能不认可这个判不过的结论——因为他们的规则里没有这条线。

### 7. 只有英文作文

这个 skill 只批改英语作文（剑桥五级体系），不支持语文作文、其他语种作文、雅思/托福作文。

### 8. 需要 AI 助手环境

需要有 Kimi Code / Claude Code / Codex CLI 之一。只用网页版 ChatGPT 或 Kimi 的老师暂时用不了。

## 待改进项（按优先级）

### P0 · 近期最该做的

1. **官方 handbook 逐页人工核对**——把 rubrics 里每条 descriptor 和剑桥官方教师指南原文对照一遍，这是唯一还没做的人工验证
2. **真实案例入库**——攒更多带老师确认分数的真实批改案例（各种题型、各种档位），特别是 FCE 和 PET story/email
3. **FCE 全流程压测**——找一篇 FCE 作文跑一遍完整流程，验证 rubric 是否过严或过松

### P1 · 中期改进

4. **批量批改模式**——一次发多篇作文，AI 排队处理，最后汇总。当前一次一篇，量大时效率有瓶颈
5. **学生进步追踪可视化**——历史对照现在是纯文字描述，可以做成简单的分数趋势图（HTML 报告里加一个小图表）
6. **更多官方样文锚点**——目前只有 PET 的 8 个锚点，KET 和 FCE 还没有

### P2 · 长期方向

7. **雅思批改**——另一套评分体系（TR/CC/LR/GRA），可以作为独立 skill 开发
8. **网页版**——让没有 AI 助手环境的老师也能用，但这需要服务器和前端，工作量远超当前 skill 的范围
9. **口语批改**——用户已有 `kpf-speaking-grading` 的姊妹 skill 方向，两个 skill 可以共享 rubric 结构

## 风险提醒

### 隐私

批改档案（HTML / PNG）含学生真实姓名和作文内容。请确保：
- 归档目录不进 Git 仓库
- 分享报告时注意未成年人隐私
- 公开仓库里的模板已用虚构数据脱敏，你自己生成的报告是你自己的责任

### 复核是前提

这个 skill 的设计前提是**老师复核后才发出去**。跳过复核直接发，等于把评分责任交给了机器——这不是这个 skill 建议的用法，也不是它设计来承担的责任。

### 自定规则 ≠ 官方标准

字数硬线、定性档位、边缘档分数线，都是本 skill 的自定规则。它们解决的是教学中的真实问题，但不代表剑桥官方口径。对外引用时建议区分「官方评分」和「我们的练习要求」。
