## 安装

### 前提

你需要有以下任一 AI 助手环境：

- **Kimi Code**（推荐，本 skill 的开发环境）
- **Claude Code**
- **Codex CLI**

这个 skill 是纯文本规则 + 脚本，不需要服务器、数据库、API key。

### 安装步骤

```bash
# 克隆仓库
git clone https://github.com/dongruiyue/kpf-writing-grading.git

# 复制到 skills 目录（二选一）
cp -r kpf-writing-grading ~/.agents/skills/    # Kimi Code / 跨运行时
cp -r kpf-writing-grading ~/.claude/skills/    # Claude Code
```

装好后重启你的 AI 助手，skill 会自动被识别。

### 验证安装

对 AI 助手说一句：

> 批改一篇 PET 作文

如果它开始问你「题目和作文请发给我」，说明 skill 已经生效。

## 日常使用

### 最简流程

1. 拍一张**作文题**的照片
2. 拍一张**学生手写作文**的照片
3. 一起发给 AI，说「批改这篇作文」

AI 会自动走六步流程，你只需要在转写确认时看一眼有没有认错字，然后等结果。

### 如果只有文字没有照片

直接把题目文字和作文文字贴进对话，说「批改这篇作文」。AI 会跳过图片识别，但**仍然会报字数、等你确认**——因为你贴的文本也可能有遗漏。

### 批量批改

一次发一篇，改完一篇再发下一篇。每次 AI 都会主动问你是否需要 HTML 报告，需要就说「生成报告」。

如果你提供了学生姓名，AI 会自动查这个学生的历史档案（在报告归档目录里），并在反馈里延续上次的观察点。

### 生成 HTML 报告

改完后 AI 会问：「需要生成 HTML 批改报告吗？」

你回答「生成」/「生成报告」/「要」，AI 就会：

1. 生成单个 HTML 文件（默认存到 `~/Documents/essay-reports/`）
2. 跑校验器（两个文件一起检查）
3. 用 Chrome 无头截图做视觉目检

然后你双击打开这个 HTML 文件，右下角有个「生成图片（发家长）」的黑色按钮，点一下整页变成 PNG 下载，直接发微信。

## 常见问题（FAQ）

### Q：AI 认错了一个字，但已经评分了，怎么办？

直接说「第 X 句的 xxx 其实是 yyy，重新评」。AI 会按修正后的文本重新走评分到反馈的全部步骤，并更新 HTML 报告。

下次批改前，如果你发现这个学生的手写有特定习惯（比如 `a` 和 `o` 不分），可以在发照片时加一句「这个孩子 a 和 o 容易认错」，AI 转写时会特别注意。

### Q：分数和我预期的不一样，怎么校准？

直接说出你的判断：

- 「Content 给高了，应该是 2」→ AI 会按你的分数重出反馈，并在 CHANGELOG 记一条校准记录
- 「这个词你认错了」→ AI 重新转写、重新评分
- 「这个表达不算错」→ AI 会把它从错误改为可选优化或删除

每次你贴回改法，skill 都会分类（A 一次性误判 / B 规则缺陷 / C 新场景 / D 自定规则调整），B/C 类改动会触发回归测试和 CHANGELOG 记录。**你的每一次纠正都在让这个 skill 变准。**

### Q：字数硬线能改吗？

能。打开 `rubrics/pet.md`（或 ket.md / fce.md），找到「字数硬线」那一段，改数字就行。这是自定规则，改它不影响官方合规。

### Q：能不能批雅思/托福作文？

不能。这个 skill 的量表只覆盖剑桥五级（KET / PET / FCE）。雅思有自己的评分体系（TR/CC/LR/GRA），不能混用。如果你需要雅思批改，那是另一个 skill 的事。

### Q：学生版反馈发微信后排版乱了？

学生版反馈是纯文本，不用 Markdown。如果你在微信里看到格式不对，检查：
1. 是不是复制时带进了多余的空格或换行
2. 微信的「引用」功能会不会改变格式
3. 直接纯文本粘贴（长按输入框 → 粘贴）

### Q：HTML 报告里的「生成图片」按钮点了没反应？

这个按钮依赖联网加载 html2canvas 组件（CDN）。如果断网，按钮会提示「改用系统截图」。联网环境下重试即可。

### Q：能改 HTML 报告的风格吗？

报告的视觉是锁死的（白底、细灰线、黑字、直角），不建议改。如果你确实需要调整，改 `assets/report-template.html` 里的 CSS，但改之前先读一遍 `SKILL.md` 第 6 步的视觉规则，别把锁死的部分改丢了。

### Q：多个老师能共用这个 skill 吗？

能。每个老师在自己的 AI 环境里装一份就行。校验器、rubrics、模板都是只读的，互不影响。批改档案存在各自电脑的归档目录里。

## 使用建议

### 什么时候用它

- **日常批改量大**：一天改 10+ 篇，AI 干粗活你复核，效率提升最明显
- **需要发家长反馈**：学生版反馈直接复制发微信，HTML 报告一键转图
- **需要存档**：HTML 报告就是批改档案，长期可查
- **需要跟踪学生进步**：提供姓名后 AI 自动对照历史档案

### 什么时候不用它

- **作文只有两三句话**：直接看一眼就改了，不需要走流程
- **需要深度教学分析**：AI 给的是评分和批改，不是教学方案。方案得你自己定
- **学生作文涉及隐私敏感内容**：报告含学生姓名和作文，注意归档目录的访问权限
